# Criando Máquinas Virtuais na Azure - Resumo do Lab

Este repositório contém um resumo prático das etapas realizadas e dos conhecimentos adquiridos durante o laboratório de criação de máquinas virtuais no Microsoft Azure, oferecido pela DIO.

## Objetivo do Lab

O principal objetivo deste desafio foi aplicar, de forma prática, os conceitos apresentados nas aulas sobre a criação e configuração de máquinas virtuais (VMs) na nuvem Azure. Além disso, o laboratório teve foco no uso do GitHub como ferramenta de documentação técnica.

## Etapas Realizadas

1. **Acesso ao Portal do Azure**
   - Acesse o [Portal do Azure](https://portal.azure.com/).
   - Navegação até a seção de Máquinas Virtuais.

2. **Criação da Máquina Virtual**
   - Escolha do sistema operacional (ex: Windows Server 2022 ou Ubuntu).
   - Definição de nome, região, imagem, tipo de máquina (SKU), e autenticação (usuário/senha ou SSH).
   - Configurações de rede, regras de firewall e recursos de monitoramento.

3. **Acesso à Máquina Virtual**
   - Para Windows: Conexão via RDP (Remote Desktop).
   - Para Linux: Conexão via SSH usando terminal ou PuTTY.

4. **Testes e Verificações**
   - Verificação de conectividade e funcionamento da VM.
   - Execução de comandos básicos para comprovar o acesso.

## Aprendizados

- Entendi o processo completo de provisionamento de máquinas virtuais no Azure.
- Aprendi a configurar opções como segurança, redes virtuais, discos e grupos de recursos.
- A experiência prática me ajudou a reforçar os conceitos de IaaS (Infraestrutura como Serviço).
- Documentar todo o processo me ajudou a fixar os aprendizados e facilitar futuras referências.

## Dicas Importantes

- Sempre revise o grupo de recursos e as políticas de região antes de criar uma VM.
- Utilize nomes padronizados e descrições claras para facilitar a gestão.
- Não se esqueça de excluir a VM ao final do teste para evitar custos desnecessários.
